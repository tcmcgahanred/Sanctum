## CTA TTPs

**20260924-F — Researchers report the first known malware that uses AI to make its own attack decisions ("ClosedQuorum"), described as an autonomous AI command-and-control implant.** Cisco Talos and others documented a new Windows malware, "ClosedQuorum," described as the first reported autonomous AI command-and-control (C2) implant — malware that uses an AI model to make decisions about how to operate on a compromised system rather than waiting for human operator commands. *Why an SLTT organization should care: this is an early, notable step in the AI-assisted-attack trajectory — malware that adapts on its own is harder to predict and detect. It is awareness-level rather than a specific patch, but it reinforces investing in behavior-based endpoint detection (which catches anomalous actions regardless of how they are decided) over signature-only tools.*
**Score:** [4.5] · adversary tradecraft (AI-driven malware) · **Answers:** PIR-4 (broad adversary-capability development)
*Sources: [BleepingComputer, "New ClosedQuorum Windows malware uses AI for attack decisions," Sep 2026](https://www.bleepingcomputer.com/news/security/new-closedquorum-windows-malware-uses-ai-for-attack-decisions/); [Cisco Talos, "The Closed Quorum: Inside the first reported autonomous AI C2 implant," Sep 2026](https://blog.talosintelligence.com/the-closed-quorum-inside-the-first-reported-autonomous-ai-c2-implant/).*

**20260924-G — Fake LastPass installers are being used to deliver a kernel-level tool that disables endpoint security, plus an information stealer.** Attackers are distributing fake LastPass password-manager installers that deploy a kernel-level "EDR killer" (which disables endpoint detection and response tools) alongside an information stealer called "Rapuncel." *Why an SLTT organization should care: this is a common and effective delivery method — trojanized installers of trusted software — that first blinds the defenses and then steals data. The defenses are download hygiene (install software only from official sources), application allow-listing, and endpoint tools configured to resist tampering. Warn staff not to download software from search-ad or lookalike sites.*

## LATEST ATTACKS OR RISKS

**20260924-H — A maximum-severity Cisco Identity Services Engine zero-day (CVSS 10.0) is being actively exploited to bypass authentication and gain root.** Cisco released urgent patches for CVE-2026-76460, a maximum-severity (CVSS 10.0) authentication-bypass flaw in Cisco Identity Services Engine (ISE) and the ISE Passive Identity Connector, after confirming active zero-day exploitation. An unauthenticated, remote attacker can send crafted requests to an API endpoint to bypass the management interface, and successful exploitation allows commands to run with root privileges — including hiding or deleting indicators of compromise. Both products are affected regardless of configuration, and there is no workaround. CISA added it to its Known Exploited Vulnerabilities catalog with a three-day federal patch-or-disconnect deadline. *Why an SLTT organization should care: Cisco ISE is a network-access-control platform that decides who and what is allowed onto the network, so a root-level compromise of it undermines access control across the whole environment. Larger SLTT and county IT shops running ISE should patch immediately (or disconnect it), and — because attackers can erase local evidence — check external network and firewall logs for signs of compromise, not just the device's own logs.*
**Score:** [4.5] · Tier 3 exploited flaw in SLTT-common technology · ×1.5 exploited/active · force-surfaced (M2) · **Answers:** PIR-3
